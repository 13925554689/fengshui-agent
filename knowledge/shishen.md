# 十神详解
#
# 十神是八字命理中的核心分析框架，以日干为"我"，
# 将其他天干与日干的关系映射为十种角色。

## 十神定义
以日干(庚)为例：

| 关系 | 阴阳相同 | 阴阳不同 | 含义 |
|------|---------|---------|------|
| 同我 | 比肩 | 劫财 | 兄弟姐妹、同事、竞争对手 |
| 我生 | 食神 | 伤官 | 才华、表达、子女、下属 |
| 我克 | 偏财 | 正财 | 财富、父亲、妻子(男) |
| 克我 | 七杀 | 正官 | 事业、权威、丈夫(女)、压力 |
| 生我 | 偏印 | 正印 | 母亲、学业、贵人、庇护 |

## 十神组合速查

### 克我者（官杀）
- **正官**: 克日干且阴阳不同 → 正规权威、事业、名声、丈夫(女)
  - 正官为用：事业有成、地位尊崇、遵纪守法
  - 正官为忌：压力过大、胆小保守、受人压制
  
- **七杀**: 克日干且阴阳相同 → 暴力权威、挑战、冒险、小人
  - 七杀为用：魄力过人、决策果断、武职显贵
  - 七杀为忌：灾祸横生、受人欺凌、冲动惹祸

### 生我者（印星）
- **正印**: 生日干且阴阳不同 → 母亲、学业、贵人、慈悲
  - 正印为用：聪明好学、贵人相助、仁慈善良
  - 正印为忌：依赖性强、缺乏主见、过于安逸

- **偏印**: 生日干且阴阳相同 → 偏门学问、继母、宗教、灵感
  - 偏印为用：特殊才能、独创思维、科研天赋
  - 偏印为忌：孤僻怪异、不合群、思虑过多

### 我克者（财星）
- **正财**: 日干克且阴阳不同 → 正当收入、妻子(男)、稳定财源
  - 正财为用：勤俭持家、收入稳定、把握机会
  - 正财为忌：吝啬小气、过于务实、缺乏格局

- **偏财**: 日干克且阴阳相同 → 意外之财、父亲、投资、慷慨
  - 偏财为用：财运亨通、投资眼光好、大方豪爽
  - 偏财为忌：挥霍无度、投机取巧、财运起伏大

### 我生者（食伤）
- **食神**: 日干生且阴阳相同 → 才华、口福、温和、享受
  - 食神为用：才华横溢、生活安逸、心胸宽广
  - 食神为忌：贪图享乐、缺乏进取、过于安逸

- **伤官**: 日干生且阴阳不同 → 创造力、叛逆、艺术、尖锐
  - 伤官为用：才华出众、创新力强、不拘一格
  - 伤官为忌：目中无人、言语刻薄、招惹是非

### 同我者（比劫）
- **比肩**: 与日干相同 → 兄弟姐妹、同事、自我意识
  - 比肩为用：独立自主、朋友助力、意志坚定
  - 比肩为忌：竞争激烈、固执己见、人气不旺

- **劫财**: 与日干五行同但阴阳异 → 朋友、竞争、消耗
  - 劫财为用：人际关系好、合作共赢
  - 劫财为忌：被朋友拖累、破财、竞争失利
