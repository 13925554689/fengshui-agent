# 大运流年判断法则

## 大运排法
- 阳年生男/阴年生女：顺排（从月柱顺数到大运干支）
- 阴年生男/阳年生女：逆排（从月柱逆数到大运干支）
- 阳年：年干为甲丙戊庚壬
- 阴年：年干为乙丁己辛癸
- 每步大运管10年

## 大运与命局的关系
1. **大运是命局的行运轨迹**，命局是静态，大运是动态
2. 大运干支与命局四柱产生：合、冲、刑、害
3. 大运引入新的五行力量，可能改变原命局的平衡

## 流年与大运的关系
1. 流年为太岁，权最大，管一年
2. 大运管十年趋势，流年管当年事件
3. **流年 > 大运 > 命局**（在事件应期上）
4. 流年大运同时作用某一柱时，该柱代表的事项应验概率最高

## 大运吉凶判断框架

### 大运是用神运
- 此十年整体运势较好
- 在此大运中的流年，逢用神年更佳，逢忌神年也不至于太差

### 大运是忌神运
- 此十年整体运势低迷
- 但若某个流年是用神，仍有好年份

### 重点关注
1. **大运天干是忌神，流年天干是用神**：此年先凶后吉
2. **大运地支与流年地支相冲**：此年变动大，可能换工作/搬家
3. **大运与命局某柱天克地冲**：此十年该柱代表的人/事受影响
4. **流年与命局年柱天克地冲**：注意长辈健康或家庭变动
5. **流年与日柱天克地冲**：自身变动最大的一年

## 流年专项

### 财运看财星
- 流年遇正财/偏财 + 为用神 → 财运上升
- 流年遇比劫 + 为忌神 → 破财、竞争失财

### 事业看官星
- 流年遇正官/七杀 + 为用神 → 升职、事业突破
- 流年遇伤官见官 → 事业变动、离职、冲突

### 感情看财官/食伤
- 男命流年遇财星 → 桃花运
- 女命流年遇官星 → 桃花运
- 流年与日柱合 → 婚恋机缘
