# 用神喜忌判断法则

## 核心原理
用神是八字中最需要的五行，取用神的目的是"平衡"命局。
基本原则：**身强宜克泄耗，身弱宜生扶**。

## 日主强弱判断

### 得令（月令）
- 日干在月支处于：长生、沐浴、冠带、临官、帝旺 → 得令，身偏强
- 日干在月支处于：衰、病、死、墓、绝 → 失令，身偏弱

### 得地（通根）
- 日干在地支有同五行之根（含藏干）越多 → 越强
- 通根力量：本气根 > 中气根 > 余气根

### 得势（党众）
- 天干比劫多（日主同类多）→ 身强
- 天干印星多（生我者多）→ 身强
- 天干财官食伤多 → 身弱

## 取用神规则

### 身强
1. 克：取正官/七杀来克制（但如果官杀已多则不用）
2. 泄：取食神/伤官来泄身（才华发泄）
3. 耗：取正财/偏财来消耗（赚钱忙碌）

### 身弱
1. 生：取正印/偏印来生扶
2. 帮：取比肩/劫财来帮助

### 特殊格局
- **从强格**: 日主极强，顺其旺势，用比劫印星
- **从弱格**: 日主极弱，顺其弱势，用财官食伤
- **化气格**: 日主与他干化合成功，以化神为用

## 用神忌神判定参考

| 条件 | 可能用神 | 可能忌神 |
|------|---------|---------|
| 日主旺 + 财弱 | 财星 | 比劫 |
| 日主旺 + 官弱 | 官星 | 食伤 |
| 日主弱 + 财多 | 比劫、印星 | 财星 |
| 日主弱 + 官多 | 印星 | 官杀 |
| 日主弱 + 食伤多 | 印星 | 食伤 |
| 日主旺 + 印多 | 财星 | 印星 |
